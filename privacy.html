PRIVACY POLICY

Privacy Policy

Last updated: October 1, 2026

"NCC Uploader" is a private tool used only by the owner of the Nature's Cheat Codes YouTube channel. It is not offered to the public.

What the tool accesses

  • With the owner's permission (Google OAuth), it uploads the channel's own videos to YouTube and reads basic statistics for those videos (for example views and watch time) through the YouTube Data API and YouTube Analytics API.
  • It does not access, collect or store data about any other YouTube users or viewers beyond the aggregated statistics YouTube provides for the channel's own videos.

How data is used and stored

  • Video statistics are used only to improve the channel's own videos.
  • Access credentials are stored as encrypted secrets and are never shared with third parties.
  • No data is sold, shared for advertising, or used to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
